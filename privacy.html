Политика конфиденциальности

Какие данные используются

ArtDirectorBot Mail получает от Google основной адрес авторизованного аккаунта и право отправлять письма от его имени. Адрес используется только для проверки, что подключён разрешённый отправитель. Приложение не получает права читать, изменять или удалять почту.

Для одного служебного письма обрабатываются утверждённое изображение недельного отчёта и два PDF-счёта, полученные ботом в Telegram.

Как используются и передаются данные

Данные используются только для создания и отправки письма заранее заданному получателю через Gmail API. Содержание письма передаётся Google для отправки и почтовому сервису получателя для доставки. Данные Google не продаются, не используются для рекламы и не передаются другим сторонам.

Хранение и защита

Разрешение OAuth хранится на закрытом рабочем сервере с ограниченным доступом. PDF загружаются из Telegram в оперативную память для отправки и отдельно на сервере не сохраняются. Изображение отчёта и технический статус отправки хранятся в рабочей базе бота. Секреты и содержимое вложений не записываются в журналы.

Удаление и отзыв доступа

Владелец может в любой момент отозвать доступ приложения в настройках безопасности Google. После отключения учётные данные OAuth удаляются с рабочего сервера. По вопросам обработки или удаления данных: zakatalovone@gmail.com.

Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.
